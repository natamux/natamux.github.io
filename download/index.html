Download

Download Natamux as a file

The fastest way is the install command: it checks the file and handles the first start for you. Download a file here when you cannot run it.

Download for Apple siliconDownload for Intel
  1. Open the .dmg and drag Natamux to Applications.

macOS blocks the first start

The app is not signed with an Apple certificate yet. Open System Settings → Privacy & Security and click Open Anyway. Or run:

xattr -dr com.apple.quarantine /Applications/Natamux.app
Download for Windows
  1. Run Natamux-win-x64.exe. It needs no administrator rights.
  2. Task terminals run PowerShell. For a new version, run the new installer; it keeps your data.

SmartScreen stops the first start

The installer is not signed with a Windows certificate yet. If you see Windows protected your PC, click More info, then Run anyway.

Download AppImageDownload .deb
  1. AppImage: make it executable, then start it. Install curl for update checks.
  2. Debian and Ubuntu: install the .deb with apt. The app is in /opt/Natamux.
sudo apt install ./Natamux-linux-amd64.deb
