01 / Workflow

Every task has a path.

Start with the default stages, or shape the process in Project settings → Stages. Commit .natamux.json to share the same workflow with your team.

  1. 01 / Start

    Give the task context

    Add notes, a GitHub issue, a skill or files. Natamux creates a worktree and a branch for the task.

  2. 02 / Run

    Agents work in stages

    Choose the agent for each stage. Test spec and Implement can run side by side, each in its own terminal.

  3. 03 / Decide

    Review at the gate

    Read the result, answer a question, approve the stage or send it back with the reason.

  4. 04 / Ship

    Read the change

    Inspect the diff, commit, push and open a pull request. Follow its checks from the task.

04 / Your agents

Bring the tools you already use.

Natamux starts the agent in the task's terminal. Hooks report when it works, asks or finishes. Give each stage its own agent and model.

A plain terminal agent works too. Its bell, natamux ask and natamux done report back.

05 / Your project

Fits the project you already have.

Your repository, your tools, your agent logins.

  • A separate worktree and branch for every task.
  • .natamux-setup prepares each new workspace. On Windows, use .natamux-setup.ps1.
  • Ten ports per task, with the first in $PORT.
  • Checks and conditions can run any shell command.
  • Export a workflow and Import... it into another project. Import lists its commands first.

Workspaces ↗

YOU + YOUR AGENTSnatamux / nmx
# Start a task
nmx task create "Export the report as CSV"
nmx agent start T-0010 --agent codex

# Ask a question, then report done
natamux ask "Keep the old CSV columns?"
natamux done

# Send findings back to Implement
natamux stage back $NATAMUX_TASK_ID \
  --to implement --reason "Empty rows break the export"
CLI reference ↗

Local first

Your workspace stays yours.

  • No Natamux account or telemetry. Task files and their history live on your machine. Your agents use their own services and logins.
  • A local daemon. It listens on 127.0.0.1 and requires a token on every request.
  • Open source. GPL-3.0 licensed. Besides update checks, Natamux talks to GitHub through your own git and gh.

06 / Get started

Download Natamux 1.0.22

You need git and at least one agent, installed and signed in. The GitHub CLI adds pull requests and issues.

Install with one command, in Terminal

curl -fsSL https://natamux.github.io/install.sh | sh

It installs Natamux in Applications, checks the file and lets macOS open it the first time.

Install with one command, in PowerShell

irm https://natamux.github.io/install.ps1 | iex

It checks the installer and runs it for your user, with no administrator rights.

Debian and Ubuntu: install with one command

curl -fsSL https://natamux.github.io/install.sh | sh

It checks the .deb and installs it with apt. On other distributions, download the AppImage.

  • Download a file instead: .dmg, .exe, AppImage, .deb and .tar.gz
  • Install guide, with what the command does
  • Release notes of 1.0.22 and the changelog
  • Run with Docker or build the Rust images in a Codespace
